# LLM出力評価Excel設計書

## 1. 目的

本書は、固定した評価用Inputに対するLLMの出力結果をExcelで管理し、LLM出力評価で定義した区分2ごとに評価するためのExcel構成を定義する。

現在の手作業による評価で利用でき、将来CSV出力や評価処理を自動化する際にも移行しやすい構成とする。

## 2. 前提

- Input設計によって、評価に使用するInputを事前に固定する
- 評価用Inputは10パターンを想定する
- 各Inputに対してLLMを10回実行する
- 合計100件のLLM出力を評価対象とする
- 各出力は、LLM出力評価で定義した区分2ごとに1〜5点で評価する
- 区分2ごとに、同一Inputから生成された10出力の平均点を算出する
- 区分2のOK／NGは、10出力の平均点をもとに判定する
- 各出力に対する個別のOK／NG判定は行わない
- 評価基準およびOK／NGの閾値は、LLM出力評価側で定義する

```text
固定Input 10パターン
×
各Inputを10回実行
=
評価対象となるLLM出力 100件
```

## 3. Excel全体構成

Excelは、出力を一元管理するシートと、区分2ごとの評価シートで構成する。

```text
00_出力一覧
01_{区分2の名称}
02_{区分2の名称}
03_{区分2の名称}
…
```

例：

```text
00_出力一覧
01_正確性
02_関連性
03_一貫性
04_指示遵守性
```

区分2のシート名は、LLM出力評価仕様書で定義した名称と一致させる。

## 6. シート間の自動反映

### 6.1 基本方針

「00_出力一覧」シートの範囲をExcelのテーブルに変換し、テーブル名を `出力一覧` とする。

区分2ごとの評価シートでは、Input IDを検索キーとして `XLOOKUP` 関数でInputと出力を取得する。

これにより、「00_出力一覧」へInputと出力を貼り付けると、すべての区分2シートへ自動的に反映される。

### 6.2 Inputの反映

```excel
=XLOOKUP($A2,出力一覧[Input ID],出力一覧[Input],"")
```

### 6.3 出力の反映

出力1：

```excel
=XLOOKUP($A2,出力一覧[Input ID],出力一覧[出力1],"")
```

出力2：

```excel
=XLOOKUP($A2,出力一覧[Input ID],出力一覧[出力2],"")
```

出力3以降も、参照する列名を変更して同様に設定する。

## 7. 平均点の計算

区分2ごとに、同一Inputから生成された10出力の評価点の平均を算出する。

評価シートの列構成が本設計書どおりの場合、W2セルへ次の数式を設定する。

```excel
=IFERROR(AVERAGE(D2,F2,H2,J2,L2,N2,P2,R2,T2,V2),"")
```

### 7.1 平均点の取扱い

- 点数は1〜5の数値とする
- 未評価のセルは空欄とする
- 未評価を0点として扱わない
- `AVERAGE` 関数は空欄を除外して平均を計算する
- 10件すべて未評価の場合は空欄を表示する
- 小数点以下の表示桁数は、LLM出力評価側のルールに合わせる

## 8. OK／NG判定

区分2の判定は、各出力を個別に判定せず、10出力の平均点から算出する。

例として、平均点3.0以上をOKとする場合、X2セルへ次の数式を設定する。

```excel
=IF(W2="","",IF(W2>=3,"OK","NG"))
```

数式内の `3` は例であり、実際にはLLM出力評価仕様書で定義した判定基準を使用する。

## 9. 評価の流れ

```text
1. Input設計で評価用Inputを固定する
2. 各InputをLLMへ10回入力する
3. 「00_出力一覧」へInputと10出力を貼り付ける
4. 各区分2シートへInputと出力が自動反映される
5. 評価者が各出力へ1〜5点を入力する
6. Inputごとに10出力の平均点が自動計算される
7. 平均点から区分2のOK／NGが自動判定される
```

## 10. 入力規則

### 10.1 Input ID

- 各Inputに一意なIDを付与する
- 推奨形式は `I-001`、`I-002`、…、`I-010` とする
- すべてのシートをInput IDで紐づける
- 行番号をシート間の紐づけに使用しない

### 10.2 評価点

- 入力可能な値は1、2、3、4、5のみとする
- Excelのデータの入力規則を使用し、1〜5以外を入力できないようにする
- 未評価の場合は空欄とする
- 数値以外の記号や文字を入力しない

### 10.3 判定

- 判定値は `OK`、`NG`、空欄のいずれかとする
- 評価者が手入力せず、平均点から数式で算出する

## 11. Excel設定

評価時の誤操作を防ぐため、次の設定を推奨する。

- 先頭行を固定する
- Input ID列およびInput列を固定表示する
- 出力列は折り返して全体を表示する
- 点数列に1〜5の入力規則を設定する
- 平均点列および判定列を数式で自動計算する
- Input・出力・平均点・判定のセルを保護する
- 評価者が編集するセルは点数列だけにする
- 判定がNGの場合は条件付き書式で強調する

## 12. 将来のCSV自動化に向けた規則

将来のCSV出力および自動評価に備え、次を守る。

- 1行目を列名として使用する
- 結合セルを使用しない
- Input IDを必須とする
- 出力列は `output_01`〜`output_10` のように連番で識別できるようにする
- 点数列は `score_01`〜`score_10` のように出力番号と対応させる
- 点数は1〜5の数値として保持する
- 未評価は空欄とし、0を使用しない
- 判定値は `OK` または `NG` に統一する
- Inputおよび出力に改行やカンマが含まれることを想定し、CSV出力時に適切に引用符で囲む
- 区分2のシート名とLLM出力評価仕様書の区分2名を一致させる

## 13. 本設計書の対象外

次の内容は本設計書では定義しない。

- 評価用Inputの洗い出し方法
- 区分2の具体的な評価項目
- 1〜5点の具体的な採点基準
- 平均点に対するOK／NGの閾値
- 区分2をまたいだ最終的な総合判定
- 使用するモデル、Prompt、実行パラメータ

これらはInput設計書、LLM出力評価仕様書、または評価実行設計で定義する。
