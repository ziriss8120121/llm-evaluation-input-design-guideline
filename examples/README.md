# Examples

このディレクトリには、ガイドラインを特定のユースケースへ適用した例を配置します。

具体的なInput Dimension、Input Pattern、組み合わせ、代表Inputはユースケースごとに設計するため、ガイドライン本体では固定しません。

## 追加時の構成例

```text
examples/
└── {use-case-name}/
    ├── input-design.md
    └── evaluation-input-dataset.json
```

例を追加する際は、[Input設計テンプレート](../templates/input-design-template.md) に沿って、DimensionからDatasetまでの判断根拠を記録してください。
